# Apollo PV Designs Website

Simple static website for Apollo PV Designs.

## Local preview

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Deployment options

Recommended first deployment: Cloudflare Pages, Netlify, or Vercel.

Suggested production domain: `apollopvdesign.com`.
